# cave-story-pocketsprite

It's Cave Story for the PocketSprite.

Upload cavestory.app and cavestory.dat to your PocketSprite, from /build/.

Also upload chooser.app for a nicer firmware.

This one is vibecoded, using Cave Story MD and my previous Cave Story Thumby port as a base. I've already spent enough weeks on gruntwork for CS Thumby and CS NES and CS2D3D, time for an easy one.
